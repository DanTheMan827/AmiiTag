# AmiiTag Screenshots

This folder contains screenshots of AmiiTag's main workflows, including scanning and writing tags, browsing amiibo data, managing lock-ons, connecting Bluetooth devices, and working with an N2 Elite.

## Main menu and tag workflow

### 1. Main menu

The AmiiTag home screen provides quick access to the amiibo library, game information, tag scanning and loading, lock-ons, N2 Elite management, Bluetooth devices, and settings.

![AmiiTag main menu](01-main-menu.png)

### 2. Scan a tag

The scan prompt asks the user to hold an NFC tag near the reader while AmiiTag waits for it.

![Scan tag prompt](02-scan-tag.png)

### 3. Tag details

The details screen identifies a scanned Kong amiibo and displays its character, game, series, type, amiibo ID, tag format, UID, and write count. Actions for writing, saving, and sharing the tag are available below.

![Kong amiibo tag details](03-tag-details.png)

### 4. Write a tag

After choosing **Write Tag**, AmiiTag prompts the user to hold the destination tag near the NFC reader.

![Write tag prompt](04-write-tag.png)

### 5. Successful write

A confirmation dialog reports that the tag's app data was written successfully.

![Tag successfully written confirmation](05-tag-successfully-written.png)

## Amiibo and lock-on libraries

### 6. Amiibo library

The amiibo library organizes figures by series and includes a search field for quickly finding a collection.

![Amiibo library series list](06-tag-library.png)

### 7. Library figures

Selecting a series opens a visual grid of its figures. This example shows the available **Kirby Air Riders** characters and vehicles.

![Kirby Air Riders figures](07-library-figures.png)

### 8. Version 3 amiibo details

The Kirby and Warp Star details page shows an amiibo v3 tag, including its larger tag format, UID, write count, assigned lock-on, and CRC validation status.

![Kirby and Warp Star amiibo v3 details](08-v3-amiibo.png)

### 9. Game usage

Further down the amiibo details page, AmiiTag lists compatible games and explains the reward or feature provided in each title. It also identifies games that save data to the figure.

![Kirby amiibo game usage list](09-game-usage.png)

### 10. Lock-on library

The lock-on library lists imported lock-on files with their names, associated figures, and import dates. It also provides an option to import additional files.

![Lock-on library](10-lock-on-library.png)

## Bluetooth devices

### 11. Bluetooth discovery

The devices screen scans for nearby supported Bluetooth hardware. A Pixl.js device is shown with its signal strength, and an option allows all Bluetooth devices to be displayed.

![Bluetooth device discovery](11-bluetooth.png)

### 12. Pixl.js storage browser

The Pixl.js management screen exposes the device's external flash storage. Users can browse folders, upload files, add a character, create folders, and refresh the listing.

![Pixl.js external flash browser](12-bluetooth-pixljs.png)

### 13. AmiiboLink controls

The AmiiboLink screen can write a tag file, character, or blank tag and switch the device among random, sequential, and read/write modes. Device information and factory reset actions are also available.

![AmiiboLink controls](13-bluetooth-amiibolink.png)

### 14. AmiLoop controls

The AmiLoop device screen offers tag-file, character, and blank-tag writing along with manual, sequential, and automatic operating modes and a device reset action.

![AmiLoop controls](14-bluetooth-amiibolink.png)

### 15. Pixl.js file management

This second Pixl.js view shows the external flash file manager and its folder and hidden-file layout.

![Pixl.js file management](15-bluetooth-pixljs.png)

### 16. Puck.js slots

The Puck.js screen displays its amiibo slots in a grid, showing populated characters, empty positions, and the currently active slot.

![Puck.js amiibo slots](16-puckjs.png)

## N2 Elite management

### 17. Connect an N2 Elite

When N2 Elite management is selected, AmiiTag asks the user to hold the device near the NFC reader to establish a connection.

![N2 Elite connection prompt](17-n2-connection.png)

### 18. Manage N2 Elite banks

The N2 Elite dashboard summarizes the active bank, enabled bank count, and banks in use. Its grid shows populated and empty banks, with actions to activate a bank or write a tag file or character.

![N2 Elite bank management](18-n2-management.png)

### 19. N2 Elite settings

The N2 Elite settings menu includes refresh, bank-count configuration, full backup, bank wiping, and device locking actions.

![N2 Elite settings](19-n2-settings.png)
